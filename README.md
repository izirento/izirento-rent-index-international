# International rent and landlord rules: catalog of country repositories

Each country has its own repository with open, source-linked data on residential rent and landlord obligations: deposits, rent increases, termination notice, lease terms and registration. This repository is the catalog: it lists the country repositories, the countries skipped with the reason, and the related EU and UK repositories. It holds no country data itself.

- Version: 2.0 (catalog; version 1.0 held all countries in one repository, see the git history)
- Facts checked: 2026-11-04
- Author: Leonid Gorok
- Project site: [izirento.com](https://izirento.com)
- Licence: CC BY 4.0 (see [`LICENSE`](LICENSE) and [`LICENSE.md`](LICENSE.md))

## Disclaimer

The data is provided as is, without any liability. We only collect and organise what the official sources publish. Laws change and local rules differ: always check each value against the primary source linked in each country repository before relying on it. This is information, not legal advice.
